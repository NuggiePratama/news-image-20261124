One Day, One Image — 24 November 2026: 50 date-checked world-news stories in one 1024×1024 image, 7 regions, a UTC timeline and a date check. Every story carries a confidence mark — [H] confirmed by 2+ sources or an official statement, [M] one source or figures that differ, [R] reported and attributed, not independently confirmed. Hero: the Huawei verdict, four tankers hit by mines in Hormuz, and Nvidia giving back its rally.

## Run it

```sh
node main.ts
```

`main.ts` runs `render.py` (pure Pillow, no network, no clock, no randomness — the same run always writes the same PNG bytes) and validates `entry.png` (1024×1024, ≥ 50 KB).
